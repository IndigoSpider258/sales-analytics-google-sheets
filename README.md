# Customer & Transaction Data Cleaning in Google Sheets

## Project Overview

This project is a recreation of a Google Sheets tutorial by Nikita Tymoshenko from the ION LAB YouTube channel.

The project follows the original tutorial and uses the datasets provided in the accompanying learning materials. The goal was to practice data cleaning, standardization, and enrichment techniques in Google Sheets.

## Data Sources

- **Tutorial:** [Nikita Tymoshenko — ION LAB](https://www.youtube.com/watch?v=gYjQRW6N6Ws)
- **Original datasets:** [MEGA folder](https://mega.nz/folder/B5ZwzSpJ#RePKaGTUzUEQS1ztS-l-Og)
- **Reference data:** Wikipedia and other sources used in the tutorial.

## Work Performed

Following the tutorial, I recreated the data preparation steps in Google Sheets, including:

- Removing duplicate records.
- Standardizing missing values.
- Splitting combined columns into separate fields.
- Formatting date values.
- Adding calculated columns, including Profit and customer age.
- Using VLOOKUP to enrich transaction data with additional customer information.
- Adding regional information using reference data.
